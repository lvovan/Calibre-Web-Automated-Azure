# RT / IE11 reading interface

- Add an isolated `/rt/` catalog and reader package, selected automatically for
  Trident clients without a feature flag. Full site remains available by cookie.
- Add IE11-compatible EPUB reading, bounded JPEG comic/PDF pages, paged TXT,
  native audio and a wrapper for the existing DjVu engine.
- Preserve existing authentication, book visibility, viewer/download permissions
  and CSRF-protected bookmarks. Keep the main theme and readers unchanged.
- Include the Surface-tested EPUB serializer/lifecycle corrections and focused
  route, header, media and browser-side regression tests.
- Fix unstyled IE11 pages by negotiating gzip/identity for RT requests instead of
  incompatible deflate assets. Add touch-sized controls, readable catalog cards
  and read-only magic shelves that keep browsing inside the RT interface.
- Add viewport-full reading, rotation-aware pagination/image fitting, 20% edge tap
  navigation and a top-center book/progress modal with an always-accessible X.
- Add comic/PDF pinch zoom and panning, exact image-page sliders, stable EPUB CFI
  position sliders and bookmark-aware close/return behavior.
